NEG/COP パラダイム比較（語幹特性 + 活用語尾）
COP だ系:
da = COP-PRS → Tense=Pres
daQ-ta = COP-PST → Tense=Past
daro-u = COP-CJC → Mood=Cjc
na = COP.ADN → VerbForm=Part
nara = COP.COND → Mood=Cnd
de = COP.GER → VerbForm=Conv
ni = COP.ADV → VerbForm=Conv
NEG ない系:
na-i = NEG-PRS → Pol=Neg|Tense=Pres
na-kaQ-ta = NEG-PST → Pol=Neg|Tense=Past
na-kereba = NEG-COND → Pol=Neg|Mood=Cnd
na-ku-te = NEG-GER → Pol=Neg|VF=Conv
na-i-de = NEG-PRS-GER → Pol=Neg|T=Pres|VF=Conv
原則: 語幹(da-/na-)が語彙カテゴリ(COP/NEG)を担い、活用語尾(-i/-ta/-roo等)がTense/Mood/VerbFormを担う。一語に共存。
